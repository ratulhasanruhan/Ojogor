# সমস্যা সমাধান

#### **সমস্যা:** "Command Not Found"

**সমাধান:** নিশ্চিত করুন যে অজগর **PATH**-এ যুক্ত আছে।

#### **সমস্যা:** স্ক্রিপ্ট রান হচ্ছে না

**সমাধান:** স্ক্রিপ্ট ফাইল এক্সিকিউটেবল কিনা দেখুন:

```sh
chmod +x script.og
```

#### **সমস্যা:** ফাইল পড়তে বা লিখতে পারছে না

**সমাধান:** অনুমতি (Permission) চেক করুন এবং ফাইলের অস্তিত্ব নিশ্চিত করুন।
