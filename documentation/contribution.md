# কান্ট্রিবিউশন

অজগর একটি ওপেন-সোর্স প্রকল্প, যেখানে সকলের অবদান স্বাগতম!

#### **বাগ রিপোর্ট করা**

যদি কোনো সমস্যা পান, তাহলে [GitHub Issues](https://github.com/ratulhasanruhan/Ojogor/issues) এ রিপোর্ট করুন।

#### **কোড অবদান রাখার পদ্ধতি**

1. রেপোজিটরি **ফর্ক** করুন।
2.  একটি নতুন ব্রাঞ্চ তৈরি করুন:

    ```sh
    git checkout -b নতুন-ফিচার
    ```
3.  পরিবর্তন করুন ও কমিট করুন:

    ```sh
    git commit -m "নতুন ফিচার যোগ করা হয়েছে"
    ```
4.  আপনার ফর্ক করা রেপোজিটরিতে পাঠিয়ে দিন:

    ```sh
    git push origin নতুন-ফিচার
    ```
5. **Pull Request (PR)** করুন।

#### **ডকুমেন্টেশন উন্নয়ন**

* যদি কোনো ভুল পান, তাহলে **Pull Request** করে সংশোধন করুন।
* নতুন ফিচারের জন্য ডকুমেন্টেশন আপডেট করুন।
