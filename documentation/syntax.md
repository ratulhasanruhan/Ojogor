# সিনট্যাক্স ও বৈশিষ্ট্য

**অজগর** একটি সহজ, মজার এবং স্যাটায়ার-ভিত্তিক প্রোগ্রামিং ভাষা। এটি দ্রুত শেখা ও ব্যবহারের জন্য তৈরি করা হয়েছে।

#### **প্রাথমিক সিনট্যাক্স**

* প্রতিটি লাইনে একটি স্টেটমেন্ট থাকবে, সেমিকোলন (`;`) ব্যবহার করতে হবে না।
* ভেরিয়েবল ডায়নামিকভাবে টাইপ নির্ধারণ করে।
* কমেন্ট যোগ করতে `#` বা `//` ব্যবহার করা যায়।

#### **ভেরিয়েবল ডিক্লারেশন**

```og
নাম = "অজগর"
সংখ্যা = ১০
```

#### **আউটপুট প্রদর্শন**

```og
দেখাও "হ্যালো বিশ্ব!"
```

#### **ইউজার ইনপুট নেওয়া**

```og
নাম = নাও "তোমার নাম কী?"
দেখাও "তোমার নাম " + নাম
```

#### **শর্ত (if-else)**

```og
যদি (সংখ্যা > ৫) {
    দেখাও "সংখ্যা বড়!"
} না হলে {
    দেখাও "সংখ্যা ছোট!"
}
```

#### **লুপ (while loop)**

```og
ধরো সংখ্যা = ০
যতক্ষণ (সংখ্যা < ৫) {
    দেখাও সংখ্যা
    সংখ্যা = সংখ্যা + ১
}
```

#### **ফাংশন ডিক্লারেশন**

```og
ফাংশন যোগ(ক, খ) {
    ফেরত দাও ক + খ
}

ফলাফল = যোগ(৫, ১০)
দেখাও ফলাফল
```
