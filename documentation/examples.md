# উদাহরণ কোড

```og
দেখাও "ওরে বিশ্ব!"
```

#### **FizzBuzz**

```og
ধরো সংখ্যা = ১
যতক্ষণ (সংখ্যা <= ১৫) {
    যদি (সংখ্যা % ৩ == ০ এবং সংখ্যা % ৫ == ০) {
        দেখাও "FizzBuzz"
    } না হলে যদি (সংখ্যা % ৩ == ০) {
        দেখাও "Fizz"
    } না হলে যদি (সংখ্যা % ৫ == ০) {
        দেখাও "Buzz"
    } না হলে {
        দেখাও সংখ্যা
    }
    সংখ্যা = সংখ্যা + ১
}
```

#### **ফ্যাক্টোরিয়াল গণনা**

```og
ফাংশন ফ্যাক্টোরিয়াল(সংখ্যা) {
    যদি (সংখ্যা <= ১) {
        ফেরত দাও ১
    }
    ফেরত দাও সংখ্যা * ফ্যাক্টোরিয়াল(সংখ্যা - ১)
}

দেখাও ফ্যাক্টোরিয়াল(৫)
```
